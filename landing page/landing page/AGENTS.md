# Sudarshan Project Conventions

## Design Tokens (Tailwind CSS Variables)
- --bg: #050713 (Deep navy cosmic)
- --panel: rgba(13, 18, 38, 0.72) (Glass/translucent panel fill)
- --text-primary: #F3F5FF
- --text-muted: #9CA6C9
- --blue-electric: #88A7FF
- --blue-bright: #6079E8
- --accent-orange: #FF9819
- --cyan-highlight: #7DE8FF
- --success-green: #68F0BB
- --border: rgba(165, 181, 255, 0.15)

## Constraints
- No raw hex values in components
- prefers-reduced-motion must be respected
- Mascot must use sudarshan-mascot.png
