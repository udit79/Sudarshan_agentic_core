# LinkedIn post

Draft from permitted evidence and a declared audience. Separate factual
claims, interpretation, and call-to-action with explicit claim bindings. Run
the deterministic humanizer audit for model self-reference, repetition,
inflated claims, generic phrasing, and unsupported certainty. Visual children
are optional: when a diagram or infographic is requested, create a typed
`SkillCall` to `visual.flowchart` and retain only its artifact and quality
references. Publishing is a separate approved side effect and is never part
of draft generation; every generated result remains `draft_only`.
